# Практическая работа №1 — Linux

## Цель работы
Познакомиться с операционной системой Linux, изучить основные команды терминала и научиться работать с файлами и каталогами.

## Выполнение работы

В ходе практической работы будут изучены следующие команды:

| Команда | Назначение |
|---|---|
| `whoami` | Показывает имя текущего пользователя |
| `pwd` | Показывает текущий каталог |
| `uname -a` | Выводит информацию о системе |
| `ls -la` | Показывает файлы и права доступа |
| `mkdir` | Создаёт каталог |
| `touch` | Создаёт пустой файл |
| `chmod` | Изменяет права доступа |

## Результаты выполнения

Здесь будут добавлены результаты выполнения команд в Linux и скриншоты терминала.
